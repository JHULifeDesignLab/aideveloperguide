## Resources & Project Ideas

### Official Documentation

- **[Vercel Documentation](https://vercel.com/docs)** — The official docs. Getting started, frameworks, and platform reference.
- **[Supported Frameworks](https://vercel.com/docs/frameworks)** — What Vercel auto-detects and how each framework is built.
- **[Environment Variables](https://vercel.com/docs/environment-variables)** — The full reference for secrets and per-environment configuration.
- **[Vercel Functions](https://vercel.com/docs/functions)** — Serverless function runtimes, limits, and configuration.
- **[Domains](https://vercel.com/docs/domains)** — Connecting and managing custom domains.
- **[Pricing](https://vercel.com/pricing)** — The current source of truth for Hobby plan limits. Check here, not blog posts.

---

### Building AI Frontends

- **[AI SDK](https://ai-sdk.dev/docs/introduction)** — Vercel's open-source library for streaming AI responses; works with Claude, OpenAI, Google, and others.
- **[Vercel Templates](https://vercel.com/templates)** — Deployable starting points, including AI chatbot templates you can dissect.
- **[Next.js Learn](https://nextjs.org/learn)** — The official free Next.js course, if you want to go deeper on the framework Vercel is built around.

### Community

- **[Vercel Community](https://community.vercel.com/)** — Official forum for deployment questions and platform help.

### Project Ideas

**Beginner**
- Deploy your portfolio site with a custom domain. Add it to your resume header and LinkedIn Featured section the same day.

**Intermediate**
- Give your RAG project a real frontend: Next.js on Vercel, streaming answers through the AI SDK, with the API key held server-side in an environment variable. Document the preview-deployment workflow in the README.

**Advanced**
- Split-deploy a full app: FastAPI backend on Render, frontend on Vercel, environment-per-branch configuration, and a README section explaining why each piece lives where it does. That explanation is interview gold.
