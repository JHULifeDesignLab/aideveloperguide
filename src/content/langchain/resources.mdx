## Resources & Project Ideas

These official docs and courses go deeper than any tutorial we could maintain — and LangChain moves fast enough that the source is the only reliable reference. Use them while you build, and treat the project ideas as resume material: each one produces both a working artifact and an informed opinion about the framework, which together are exactly what AI-team interviewers probe for.

### Official Documentation

- **[LangChain Python Docs](https://python.langchain.com/docs/introduction/)** — The source of truth. Given how fast the API moves, prefer this over any tutorial.
- **[LangChain JS Docs](https://js.langchain.com/docs/introduction/)** — The TypeScript/JavaScript version, if your stack is Node.
- **[LangGraph](https://langchain-ai.github.io/langgraph/)** — Stateful agent workflows; the production-grade part of the ecosystem.
- **[The Lang-Family, Untangled](/aideveloperguide/langchain/family)** — Our five-minute guide to LangChain vs. LangGraph vs. LangFlow, and which to name on a resume.
- **[LangSmith Docs](https://docs.smith.langchain.com/)** — Tracing, debugging, and evaluation for LLM pipelines.
- **[LangChain GitHub](https://github.com/langchain-ai/langchain)** — Source, issues, and release notes — useful for tracking API changes.

### Project Ideas

**Beginner**
- Build the Step 1 chain (prompt → model → parser) twice: once with LangChain, once with the raw provider SDK. Write a short README comparing the two — that comparison *is* the deliverable.

**Intermediate**
- Document Q&A over your own course notes (Step 2), deployed behind a FastAPI endpoint on [Render](/aideveloperguide/render), with the retrieval knobs (k, chunk size) exposed as query parameters so you can demo their effect live.

**Advanced**
- An agent with two custom tools (e.g., a vector-store retriever and a live API), traced in LangSmith, with a 10-question evaluation dataset and a README section on where the agent failed and how you fixed it. That failure analysis is the strongest artifact on this page.
