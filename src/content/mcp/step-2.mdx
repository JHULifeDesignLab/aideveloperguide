## Goal
Connect ready-made MCP servers to a host you already use and *feel* what tool-use changes — the fastest way to make the architecture concrete.

---

## Start with Claude Code

If you did our [Claude Code guide](/aideveloperguide/claude-code), you already have a host installed. Servers are configured in your settings file — for example, the filesystem and SQLite servers:

```json
{
  "mcpServers": {
    "sqlite": {
      "command": "uvx",
      "args": ["mcp-server-sqlite", "--db-path", "./local.db"]
    }
  }
}
```

Restart, and Claude can now query that database as part of any coding task — the same way it uses its built-in tools. The [official Claude Code MCP docs](https://docs.anthropic.com/en/docs/claude-code/mcp) cover the exact configuration for your platform.

---

## What to try (an hour, well spent)

1. **Connect the SQLite server** to a database from any class project and ask the host to describe the schema, then write a query. Notice what changed: it's not summarizing a schema you pasted — it's *looking for itself*.
2. **Browse the [community servers list](https://github.com/modelcontextprotocol/servers)** — hundreds exist: GitHub, Postgres, Google Drive, Slack, browsers. Pick one relevant to a project you actually have and connect it.
3. **Watch the tool calls.** Hosts show you each call the model makes and ask approval for sensitive ones. Read them — this visible loop of *decide → call → observe → continue* is the agent pattern from the [agents overview](/aideveloperguide/agents), happening live.

## Check yourself

Done when you've connected at least one server, watched the model choose to call it (and observed the approval flow), and can describe one task that went from impossible to easy because the tool existed.
