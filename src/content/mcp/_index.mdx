## About
MCP — the Model Context Protocol — is an open standard for connecting AI models to the outside world: your files, your databases, your APIs, your tools. Before MCP, every app that wanted its AI to check a calendar or query a database wrote custom glue code for each connection. MCP replaces that with one standard interface — the reason it gets called "the USB-C of AI."

It was created by Anthropic, is now stewarded openly, and has been adopted across the industry — which is why it shows up in AI job postings and why it appears all over this site: [agents](/aideveloperguide/agents) use it to act, [Claude Code](/aideveloperguide/claude-code) speaks it natively, and our [Projects page](/aideveloperguide/resources/projects) has a whole category built on it.

## What you'll accomplish

- **Understand the architecture** — hosts, clients, and servers, and the three things a server can offer (tools, resources, prompts)
- **Use existing servers** — connect ready-made MCP servers to Claude Code and feel what tool-use changes
- **Build your own server** — a small, working MCP server with the official SDK, tested and documented for your portfolio

## Why MCP specifically?

Because it's the rare thing that is both genuinely new and genuinely standard. Learning one protocol gives you access to a whole ecosystem of servers other people have built — and building your own server is a compact, impressive project: it demonstrates API design, tool-use understanding, and current-AI literacy in a single weekend-sized artifact. "Built and published an MCP server" is a resume line very few students can claim yet.
