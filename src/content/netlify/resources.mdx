## Resources & Project Ideas

Official references below — they stay current as the platform changes, which is exactly why we link instead of re-explaining. Use the docs to unblock yourself mid-deploy, and the project ideas to produce what actually matters for job applications: live URLs with explainable workflows behind them.

### Official Documentation

- **[Netlify Documentation](https://docs.netlify.com/)** — The official docs: deploys, redirects, functions, forms, per-framework settings.
- **[Redirects & Rewrites](https://docs.netlify.com/routing/redirects/)** — The full `_redirects` syntax, from SPA fallbacks to proxying.
- **[Forms](https://docs.netlify.com/manage/forms/setup/)** — Backend-free form handling and its limits.
- **[Pricing](https://www.netlify.com/pricing/)** — The source of truth for free-tier allowances.

### Project Ideas

**Beginner**
- Deploy your portfolio with a working Netlify-powered contact form and a custom 404 page. Total backend code required: zero.

**Intermediate**
- Take any React project and make it production-respectable: SPA redirects, environment-separated config, deploy previews on PRs, and a README section documenting the build settings and why.

**Advanced**
- Ship a small AI feature entirely on Netlify: static frontend + a function that calls an LLM with the key held server-side, with the same app also deployed on Vercel — and a short written comparison of the two experiences. That comparison doc is a genuinely strong portfolio artifact.
