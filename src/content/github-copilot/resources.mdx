## Resources & Project Ideas

The official references below stay current as Copilot's features shift — which they do, fast. Use them to keep your setup sharp, and use the project ideas to turn "I use Copilot" into documented evidence of judgment: that's the version employers believe.

- **[GitHub Student Developer Pack](https://education.github.com/pack)** — Free Copilot Pro for verified students, plus a long list of other developer tools.
- **[Copilot Features](https://github.com/features/copilot)** — The current feature set and what's on which plan.

### Project Ideas

**Beginner**
- Claim the Student Pack, then spend one week on a real assignment keeping the saved-me / confidently-wrong log from Step 1. Publish the summary as a short write-up — it's an honest artifact very few students produce.

**Intermediate**
- Use Copilot Chat's `/tests` workflow to bring a project of yours from no tests to meaningful coverage, reviewing every generated test for what it actually asserts. Document which generated tests you rejected and why.

**Advanced**
- The three-tool bake-off from our [Cursor guide](/aideveloperguide/cursor/resources): same feature, built with Copilot, Cursor, and Claude Code — with time, diff quality, and failure notes. This single document answers the interview question the entire category raises.
