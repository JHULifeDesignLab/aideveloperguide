## About
GitHub Copilot is the most widely deployed AI coding assistant in the industry — Microsoft's pair programmer, living inside the editor you already use. It completes code as you type, answers questions in chat, and increasingly handles multi-file edits, all without leaving VS Code (or JetBrains, or Neovim).

For students it has one unbeatable feature: **it's free** — Copilot Pro is included in the [GitHub Student Developer Pack](https://education.github.com/pack) for verified students. That makes it the zero-cost, zero-friction way to build the AI-assisted habits this site teaches, and the tool you're most likely to find already approved at an internship.

## What you'll accomplish

- **Set up free and learn completions properly** — the Student Pack, and using inline suggestions with calibration instead of autopilot
- **Use chat, edits, and context deliberately** — Copilot Chat, multi-file edits, and controlling what the model sees
- **Build the judgment layer** — review discipline, and an honest comparison with Cursor and Claude Code

## Why Copilot specifically?

Reach and price. It's the assistant with the largest install base — meaning it's the one your internship team most likely runs, the one with the deepest GitHub integration, and the one you can use for free right now with a .edu email. It's historically been shallower than [Cursor](/aideveloperguide/cursor) or [Claude Code](/aideveloperguide/claude-code) on autonomous multi-file work, and this guide is honest about where each wins — but "I've used all three and here's how I choose" is the strongest sentence a student can say in this space.
