## Resources & Project Ideas

The links below stay current with a tool that changes weekly — check the changelog the way you'd check release notes at a real job. Use the docs and forum to sharpen your setup, then pick a project idea: each one turns daily tool use into evidence (a rules file, an annotated diff, a comparison) that shows employers you direct AI rather than just accept its output.

### Project Ideas

**Beginner**
- Spend one week doing a class assignment entirely in Cursor with Tab and Cmd+K. Keep a running note of every wrong suggestion you caught — that log is a better artifact than the assignment.

**Intermediate**
- Write a `.cursor/rules` file for a group project and document before/after agent behavior with concrete diffs. Share it with your team; "I standardized our AI tooling" is a real resume line.

**Advanced**
- Build the same small feature three times — Cursor agent, Claude Code, and by hand — and write a short comparison: time, diff quality, what each tool got wrong, which you'd choose for what. This directly produces the interview answer from Step 3, backed by evidence.
