## About
Cursor is a code editor built around AI from the ground up — a fork of VS Code where autocomplete predicts multi-line edits, chat understands your whole codebase, and an agent mode can carry out multi-file changes while you review the diffs. For many developers it's the lowest-friction way to work with AI daily, because it lives exactly where you already work: the editor.

This guide gets you productive fast, then focuses on what actually differentiates you: using the tool with judgment. Anyone can accept suggestions; the skill employers notice is directing the AI, reviewing its work, and knowing which tool fits which task.

## What you'll accomplish

- **Set up in minutes** — import your entire VS Code configuration, and learn Tab autocomplete and inline edits
- **Use the real power features** — codebase-aware chat with @-references, and agent mode for multi-file changes
- **Build judgment** — project rules, diff-review discipline, and an honest comparison against Claude Code and Copilot

## Why Cursor specifically?

Because the editor is where coding happens, and Cursor's bet — AI woven into every editing surface rather than bolted on — has made it the most talked-about developer tool of the AI wave. It pairs naturally with the rest of this guide: the same LLM concepts from [LLM Basics](/aideveloperguide/llm-basics) explain both its magic and its failure modes.

It is not the only answer, and this guide won't pretend otherwise: Claude Code owns terminal-first agentic work, and Copilot is the incumbent inside plain VS Code. Step 3 gives you the comparison as an interview-ready answer instead of a fan opinion.

## How this guide works

1. **Step 1 – Setup & Tab:** Install, import settings, claim the student offer, and learn the two everyday features.
2. **Step 2 – Chat & Agent Mode:** Codebase-aware questions, @-references, and supervised multi-file edits.
3. **Step 3 – Rules & Judgment:** Encode your project's conventions, review with discipline, and know when to reach for a different tool.
