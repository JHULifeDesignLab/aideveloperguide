# Further Learning

<div id="cloud-deployment-guides">
## Cloud Deployment Guides
</div>

It's tempting to think that with AI doing so much of the work, infrastructure knowledge doesn't matter anymore. It's the opposite. Every AI product, every LLM API call, every vector database, every model deployment runs on cloud infrastructure — the industry expects cloud skills and AI skills together.

Scalability is what separates a side project from something real. Cloud platforms give you managed compute, auto-scaling, logging, security, and global distribution out of the box. Learning this as a student means you can speak the language that engineering teams actually use on the job. These step-by-step guides cover the three industry-standard clouds — deeper and more involved than the quick-ship hosts on the homepage, and worth learning once you're ready to take a project further.

**Not sure which to pick? Start with Google Cloud.** It has the most beginner-friendly learning path, gives you a verifiable skill badge after about an hour, and Vertex AI is increasingly relevant for anyone building with LLMs.
