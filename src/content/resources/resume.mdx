## What to add from this guide

Each path in this guide is designed to leave you with at least one concrete resume line. Here's how to translate what you did into language that reads well to recruiters and hiring managers.

### Cloud certifications & skill badges

Don't just say "completed course." Name the credential and the platform:

- **Google Cloud** → "Earned Google Cloud Generative AI for Developers skill badge (Vertex AI, model evaluation, responsible AI)"
- **Amazon AWS** → "Completed AWS Generative AI for Developers Professional Certificate; built contextual chatbot with Bedrock Knowledge Bases"
- **Microsoft Azure** → "Completed Azure AI Engineer learning path; deployed RAG-backed chat app using Azure AI Search and OpenAI Service"

### Projects

Frame projects around what they do and what they demonstrate, not just what tech they use:

> Built a retrieval-augmented generation (RAG) pipeline using LangChain, OpenAI embeddings, and Pinecone — grounded LLM responses in a private document corpus, reducing hallucination on domain-specific queries.

That single sentence covers: RAG, LangChain, embeddings, vector databases, and practical AI engineering judgment.

### AI tooling experience

Being able to say you use Claude Code, Cursor, or Copilot in a real workflow is worth listing under tools — but only if you can explain *how*:

> Used Claude Code for agentic code review and multi-file refactors; understand context window tradeoffs and progressive prompting strategies.

That's different from "familiar with AI tools" — it signals actual understanding.

## Resume do's and don'ts

**Do:**
- Quantify where you can ("reduced manual review time by ~40%", "deployed to 3 cloud regions")
- Use the exact credential name (ATS systems match keywords)
- List the specific services you touched (Vertex AI, Bedrock, Azure OpenAI — not just "Google/AWS/Azure")
- Link to your GitHub project in the description

**Don't:**
- Write "familiar with AI" — everyone says that now
- List tools you only watched a tutorial on
- Use vague verbs like "worked on" or "helped with"
- Put certifications in a separate section if you can tie them to a project

## Bullet formula that works

> **[Strong verb]** + **[what you built/did]** + **[tech used]** + **[result or scale]**

Examples:
- "Designed and deployed a RAG pipeline on AWS Bedrock with Knowledge Bases, achieving sub-2s retrieval latency on a 50k-document corpus"
- "Built a model card and bias evaluation report for a fine-tuned sentiment classifier, following Google's Responsible AI framework"
- "Configured Claude Code agentic sessions with CLAUDE.md and custom hooks to automate multi-file TypeScript refactors"
