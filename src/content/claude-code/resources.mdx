### Project Ideas

These are real, portfolio-worthy projects that can be completed in a weekend and demonstrate genuine Claude Code skills:

**Beginner**
- Write a `CLAUDE.md` for an existing personal project. Add project context, coding conventions, and explicit "don'ts." Document what changed about Claude's output before and after.

**Intermediate**
- Set up a hook that runs your test suite against any file Claude edits. Configure it to block Claude from proceeding if tests fail. Document the setup.
- Build a simple CLI script using the Claude Agent SDK that takes a GitHub issue URL and outputs a proposed implementation plan.

**Advanced**
- Set up an MCP server connecting Claude Code to a local SQLite database in one of your projects. Build a feature using it — e.g., ask Claude to read the schema and help you write a typed query layer.
- Design a multi-agent workflow: one agent explores and maps a codebase, another implements a feature based on that map. Compare output quality to a single-agent approach.
